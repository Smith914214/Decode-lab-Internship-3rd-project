# Random Password Generator

## Overview

The Random Password Generator is a simple Python project that creates secure and random passwords based on the length specified by the user. It uses Python's built-in `random` and `string` modules to generate passwords containing uppercase letters, lowercase letters, and digits.

## Features

* User-defined password length
* Generates random and secure passwords
* Uses letters (A-Z, a-z) and numbers (0-9)
* Easy to understand and beginner-friendly

## python password_generator.py

1. Enter the desired password length.
2. The program will generate and display a random password.

## Example

Input:- Enter password length: 10

Output:- Generated Password: A7kP2mX9qL

## Learning Outcomes

* Understanding Python modules
* Working with strings
* Using loops and randomization
* Building a basic security tool
